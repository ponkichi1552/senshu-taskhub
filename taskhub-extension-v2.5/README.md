# 課題通知Hub連携 拡張機能 v2.5.13

専修大学のinCampusから課題・お知らせ・提出通知を抽出し、課題通知Hubへ送るChrome拡張機能です。Google Classroomのページは読み取りません。Classroomの課題・提出状況は、課題通知Hub本体のGmail同期・Classroom API同期が扱います。

## 現在の機能

- inCampusホームで更新一覧を読み、通知本文の先頭で課題・お知らせ・提出を識別し、課題だけ詳細ページを取得してHubへ一括送信
- inCampusの課題詳細ページから、表示中の課題を手動抽出・送信
- 送信前のプレビュー、同期結果、設定チェック
- 同期対象を10・25・50件から選択
- 大学からのお知らせ画面を、保存済みのWebアプリURLから開く
- inCampusホームへの到達を検出して自動同期。連続実行は10分間隔で抑制

inCampusのID・パスワードは読み取りません。APIトークンはChromeの拡張機能ストレージに保存し、HubへのPOST本文にだけ含めます。

## インストール

1. Chromeで `chrome://extensions/` を開き、デベロッパーモードを有効にする
2. 「パッケージ化されていない拡張機能を読み込む」を押す
3. この `taskhub-extension-v2.5` フォルダーを選ぶ
4. 拡張機能をツールバーに固定する

## 初期設定

1. 拡張機能のポップアップに課題通知HubのGAS WebアプリURLを入力する
2. Hubのセキュリティ設定で発行したAPIトークンを入力する
3. 必要なら「設定チェック」でURL疎通とinCampus上のスクリプト注入状態を確認する
4. 初回動作は「プレビューのみ」をONにし、「更新一覧から同期」を押して抽出結果を確認する
5. 内容を確認した後にプレビューをOFFにするとHubへ保存される

自動同期を止める場合は「inCampus自動同期」をOFFにします。手動同期は引き続き使用できます。

## 動作確認

- inCampusホームで「設定チェック」を実行し、GAS URLとcontent.jsの両方がOKになること
- 「プレビューのみ」をONにして「更新一覧から同期」を実行し、課題・お知らせ・提出の内訳を確認する
- 課題詳細ページで「inCampusこのページから抽出」を実行し、JSONが表示されること
- 実データをHubへ送る場合だけプレビューをOFFにする

拡張機能を再読み込みした後、すでに開いていたinCampusページにも変更を反映するには、そのページを再読み込みしてください。

## Classroomとの分担

v2.5.9から、拡張機能によるClassroom画面の読み取り・自動同期・期限時刻補正を削除しました。manifestにもClassroomのサイト権限とcontent script対象を設定していません。Classroom連携は課題通知Hub本体のGmail同期およびClassroom API同期で行います。

## v2.5.13 の検証・修正

- 本文の改行を保持し、添付ファイル欄の非表示ファイル名・保存パス・検査状態を除外します。提出された成果物自体は収集しません。
- 括弧を含む課題名を保持します。IDが欠けた行は課題URLと更新行IDで補い、異なるお知らせをまとめません。
- ログイン画面へのリダイレクト・更新一覧の構造変更・詳細ページの失敗を検出します。inCampusの各読み取りは15秒で打ち切ります。
- 課題の取得は最大4並列です。同じ詳細URLは1回だけ読み、取得順が入れ替わっても結果の順番を維持します。
- 別タブの同期開始も排他制御します。中断したタブの予約は最大5分で期限切れになります。
- 成功・プレビュー・失敗の時刻を分けます。失敗後の自動再試行抑制は1分、成功後は10分です。手動同期は時間制限を待たず実行できます。
- 対象件数の上限で未取得になった件数を表示します。既定は25件、最大50件です。更新一覧から消えた通知は取得できません。
- 保存結果が欠けた応答や課題ごとの失敗を成功件数に含めません。プレビューは送信前にも確認します。
- Hub側では、Sheetsが日時文字列をDate型にした場合も同じ値として比較し、変更のない課題の保存・表示データ再生成を省きます。24:00は記載日の23:59、00:00は前日の23:59として表示します。

保存先は利用者の個人用 `inCampus通知` シートの `extract` 行です。表示キャッシュの有無と、共有テストデータを表示中かどうかは保存先を変えません。Gmail由来の通知を正本とする既存の表示照合は維持します。

`pnpm test` は実際のinCampusのDOM構造に基づく仮想HTMLで、分類・改行・添付・提出通知・通信失敗・タイムアウト・複数タブ・保存応答・Date型変換を検証します。実ユーザーのHTMLや保存データはテストに含めません。
