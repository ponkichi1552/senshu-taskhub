# 課題通知Hub連携 拡張機能 v2.5.5

ログイン済みのinCampusから課題情報を抽出し、Google Classroomから完了状態と期限時刻を同期するChrome拡張です。

`/portal/home` に到達すると、裏で `/updateinfo` を読み、`module=report` の課題通知から課題詳細ページを取得して課題通知Hubへ送信します。ログイン後のリダイレクトやinCampus内の画面遷移でもホーム到達を検出します。

v2.0ではGoogle Classroomの「完了」ページから提出済み課題を読み取り、Gmailから保存済みのClassroom課題を `完了` に更新できます。

v2.1ではGoogle Classroomの「未提出」ページから期限時刻を読み取り、Gmail側で時刻まで取れていないClassroom課題の期限を補正できます。

v2.2ではGoogle Classroomの「未提出」ページと「完了」ページへの到達を検出し、自動同期がONなら期限時刻同期・完了同期を自動で実行します。

v2.3ではGoogle Classroomホーム `https://classroom.google.com/h` を開いた時にも、未提出ページと完了ページへ順番に移動して期限時刻同期・完了同期を自動実行します。Classroom自動同期のON/OFFと、未一致結果の表示も追加しました。

v2.4ではClassroomホーム同期を画面遷移なしの裏読み方式に変更しました。`https://classroom.google.com/` と `https://classroom.google.com/h` の両方をホームとして扱い、未提出ページ・完了ページをhidden iframeで読み込んで同期します。

v2.4.1では直近結果の内訳を全件表示し、Classroomの未一致項目を先頭にまとめて確認できるようにしました。

v2.5では配布時にユーザーごとの保存先スプレッドシートを自動作成・記録する方式にしました。GAS側へ反映する同梱ファイルは `Code.gs` です。

v2.5.1ではGAS WebアプリへのPOSTにAPIトークン認証を追加しました。拡張機能側にAPIトークンを保存し、送信時のJSON本文に `apiToken` を同梱します。

v2.5.5ではClassroom同期の照合をURL・ClassroomパスID・同期ID優先にし、保存済みメール課題と確実に結びつく場合だけ期限時刻補正・完了反映を行います。

  - inCampus内のリダイレクトや画面遷移、タブ復帰、表示復帰を検出して同期する仕組みを追加

  - 直近同期結果の表示、10分間隔の自動同期抑制、自動同期ON/OFFを追加
- v1.2（manifest 0.2.4）
  - `/updateinfo` の `課題（...）を提出しました` 形式を提出済み記録として扱うように追加

  - 同期結果の件数表示を `課題` と `提出` に分けて確認できるように改善
  - 課題名抽出で `課題「...」` 形式にも対応

  - 自動同期・手動同期の両方で同期対象件数の設定を反映するように変更
  - プレビュー時はGAS WebアプリURL未設定でもinCampus側の抽出確認ができるように変更

## 使い方

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. この `incampus-hub-extension` フォルダを選ぶ
5. inCampusに普通にログインする
6. 拡張機能アイコンを開く
7. GAS WebアプリURLを入力する
8. 課題通知Hub本体のセキュリティ設定でAPIトークンを再発行してコピーし、拡張機能のAPIトークン欄に入力する
9. 必要に応じて「設定チェック」を押して、URL・APIトークン・現在のタブ・content.jsの状態を確認する
10. 必要に応じて「inCampus自動同期」「Classroom自動同期」をON/OFFする
11. 必要に応じて「同期対象件数」を 10 / 25 / 50 件から選ぶ
12. inCampusのホーム `https://ic.ss.senshu-u.ac.jp/portal/home` を開く
13. 自動同期がONなら、inCampusホーム到達時に更新一覧から課題情報を抽出してHubへ送信されます
14. Classroom自動同期がONなら、Classroomホーム、`未提出` ページ、`完了` ページで自動同期します

手動で試したい場合は、inCampusのページを開いた状態で「更新一覧から同期」を押してください。

「プレビューのみ」をONにしてから「更新一覧から同期」を押すと、抽出結果の確認だけ行い、Hubへは送信しません。GAS WebアプリURLが未設定でも、inCampus側の抽出確認に使えます。

課題詳細ページ単体から確認したい場合は、課題詳細ページで「このページから抽出」を押すと、画面のHTMLから抽出したJSONを確認できます。

Classroom完了状態を同期したい場合は、Google Classroomの `完了` ページを開いた状態で「Classroom完了同期」を押してください。表示中の完了済み課題から課題URL・タイトル・授業名を取り、Gmailから保存済みのClassroom課題と照合して完了にします。

Classroom期限時刻を同期したい場合は、Google Classroomの `未提出` ページを開いた状態で「Classroom期限同期」を押してください。表示中の未提出課題から `明日 23:59` や `木曜日 23:59` のような期限表示を読み取り、Gmailから保存済みのClassroom課題と照合して期限セルを補正します。

Classroom自動同期がONの場合は、Google Classroomの `未提出` ページ到達時に期限同期、`完了` ページ到達時に完了同期も自動実行されます。Classroomホームを開いた場合は、未提出ページと完了ページを裏で読み込んで同期します。画面はホームのままです。

「直近結果」を押すと、最後の同期結果を `検出 / 新規 / 更新 / 失敗` の件数と、各項目の新規・更新・確認ログで確認できます。プレビュー時は `新規` の代わりに `確認` が表示されます。Classroom同期で未一致がある場合は、未一致項目を先頭にまとめて表示します。

## 仕様

- inCampusのID/パスワードは読み取りません。
- 自動同期では `/updateinfo` と課題詳細ページのHTMLを読みます。
- `/updateinfo` に `課題（...）を提出しました` がある場合は、提出済み記録としてHubへ送信します。
- 手動抽出では現在表示中の課題詳細ページのHTMLだけを読みます。
- `Code.gs` をApps Script側に反映すると、スプレッドシートへ送信できます。保存先IDを空のままにして、Webアプリを「アクセスしているユーザーとして実行」でデプロイすると、ユーザーごとに保存先スプレッドシートを作成します。
- 配布用デプロイでは「実行ユーザーは自分」を選ばないでください。その設定で共有すると、保存先スプレッドシート、Gmail取り込み、APIトークンがデプロイ所有者側に集約されます。
- v2.5.5のClassroom連携を使う場合は、同梱の `Code.gs` をデプロイしてください。
- 抽出対象は `.contents-detail` 内のラベルと値です。HTML構造が少し変わった場合に備えて、table / dl / 見出しからも補助的に抽出します。
- 自動同期はinCampusホーム、Classroomホーム、Classroom未提出ページ、Classroom完了ページへの到達、タブ復帰、表示復帰を検出して実行します。
- inCampus自動同期とClassroom自動同期はポップアップから個別にON/OFFできます。OFFでも手動同期は実行できます。
- 同期対象件数は 10 / 25 / 50 件から選べます。自動同期・手動同期の両方に反映されます。
- プレビューのみONでは `/updateinfo` と詳細ページを読みますが、HubへのPOSTは行いません。
- HubへPOSTするには、GAS WebアプリURLとAPIトークンの両方が必要です。APIトークン未設定時は自動同期も送信前に停止します。
- APIトークンはChrome拡張のローカルストレージに保存され、POST時のみJSON本文の `apiToken` として送信されます。URLクエリには付けません。Hub本体のセキュリティ画面では保存済みトークン本体を再表示せず、再発行直後だけコピーできます。
- 送信データが大きすぎる場合は拡張機能側で止めます。必要に応じて同期対象件数を減らしてください。
- 同期結果には、Hub側で新規追加された項目、既存行として更新された項目、プレビュー確認だけ行った項目の内訳を保存します。
- Classroom完了同期では、既存のGoogle Classroom課題行の `確認状態` だけを `完了` に更新します。既存行と照合できない場合は、新規保存せず未一致として扱います。
- Classroom完了同期と期限同期では、折りたたまれているClassroom見出しを可能な範囲で自動展開してから抽出します。
- Classroom期限同期では、URL・ClassroomパスID・同期IDで既存行と照合できたGoogle Classroom課題行だけ、`期限` と `期限状態` を更新します。`期限状態` は `Classroomで時刻補正` になります。
- 自動同期は短時間に何度も走らないよう、inCampus、Classroomホーム、Classroom期限同期、Classroom完了同期ごとに10分間隔で抑制します。
- 「設定チェック」では、GAS URL形式、GAS URLへのGET疎通、inCampusタブ、content.js注入状態を確認します。

## 抽出される主な項目

- `title`: タイトル
- `body`: 内容
- `startAt`: 提出開始日時
- `dueAt`: 提出終了日時
- `lateSubmission`: 期間外提出
- `assignmentType`: 課題種別
- `pageUrl`: 抽出元ページURL
- `assignmentKey`: 更新判定用キー

## 注意

この拡張は検証用です。抽出結果には授業名、課題内容、URLなどの学内情報が含まれる可能性があります。スクショやJSONを共有するときは個人情報・授業情報・URLを確認してください。

## GAS側の準備

1. 課題通知Hubのスプレッドシートに紐づくApps Scriptを開く
2. 同梱の `Code.gs` をApps Script側のメインGASファイルへ反映する
3. `デプロイ` → `新しいデプロイ` → `ウェブアプリ`
4. 実行ユーザーは「ウェブアプリケーションにアクセスしているユーザー」
5. アクセスできるユーザーは「Googleアカウントを持つ全員」または配布したい組織内ユーザー
6. `/exec` で終わるWebアプリURLを配布し、利用者はそのURLを自分のGoogleアカウントで開く
7. 課題通知Hub本体のセキュリティ設定を開き、APIトークンを再発行して拡張に入力する

利用者は初回アクセス時にGoogleの承認画面を進めます。承認後は、その利用者のGoogleアカウント側で保存先スプレッドシートとAPIトークンが作成・管理されます。

inCampusから送信された課題は `inCampus抽出` シートに保存されます。同じ `assignmentKey` または `pageUrl` が既にある場合は追記ではなく更新します。

Classroom完了同期は `通知一覧` シートのGoogle Classroom行を対象にします。Gmailから保存済みの課題URLと、Classroom完了ページから取得した課題URLを正規化して照合し、一致した行の `確認状態` だけを `完了` にします。照合できない場合は新規行を作らず、未一致として扱います。

Classroom期限同期も `通知一覧` シートのGoogle Classroom行を対象にします。Gmailから保存済みの課題URLと、Classroom未提出ページから取得した課題URLを正規化して照合し、一致した行の `期限` を時刻つきに更新します。照合できない場合は新規行を作らず、未一致として扱います。

## 自動同期の判定ルール

- `/updateinfo` 内の `.update-info-student` を見る
- hidden input の `module` が `report` の通知だけを対象にする
- `button.updateInfoUrl` の `value` から課題詳細ページURLを作る
- 更新一覧本文が `課題（...）を提出しました` の場合は詳細ページを取得せず、提出済み記録として送信する
- 同期対象件数の設定に応じて、先頭から最大 10 / 25 / 50 件を処理する
- 詳細ページの `.contents-detail` から以下を抜き出す
  - タイトル
  - 内容
  - 添付ファイル
  - 提出期間
  - 期間外提出
  - 課題種別
